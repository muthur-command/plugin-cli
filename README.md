# MCOS CLI plugin

中文文档: [`README.zh-CN.md`](./README.zh-CN.md)

Supervisor-managed **CLI** add-on for **MCOS** (interactive `mc` shell on **`ghcr.io/muthur-command/base`**; OCI labels **`io.mcio.*`**).

The `mc` binary is downloaded at image build time. The Dockerfile defaults to **`muthur-command/cli`** releases; CI temporarily overrides to **`home-assistant/cli`** until matching assets exist on your fork (see **README.zh-CN.md**).
